# 케이네 서당 학습 개발본 v2 — 로마자 입력 및 정답 확인

이 파일이 이번 v2 변경 안내입니다. 이전 README_LESSONS_V1.md와 verification 폴더는 이전 단계의 기록으로 보존했습니다.

## 실행

전체 ZIP을 새 폴더에 풀고 기존 START_SCHOOL_DEV.bat을 실행합니다. http://localhost:8896/ 주소와 기존 저장 키를 유지합니다. 인간마을 → 서당 입구 F → 케이네 F → 대화를 넘겨 '새로운 단어 배우기'를 선택합니다.

기존 v1 개발본을 보유한 경우 패치 ZIP을 그 개발본 게임 루트에 풀 수 있습니다. 정식 GitHub 게임 폴더에는 적용하지 않습니다. 실행 중인 이전 개발 서버가 있다면 먼저 해당 콘솔을 종료하고 새 복사본에서 시작합니다.

## 입력 규칙

| 단어 | 히라가나 정답 | 허용 로마자 | 오답 예시 |
| --- | --- | --- | --- |
| 学校 | がっこう | gakkou, gakkō | gakko, gakou, gako, がこう, がっこ |
| 先生 | せんせい | sensei | sense, sensi, sensee, せんせ |
| 本 | ほん | hon | ho, honn, ほ |

- 로마자는 대소문자를 구분하지 않습니다. 예: GAKKOU, GaKkŌ, SENSEI, HON.
- 허용 로마자는 단어별 명시적 목록으로 관리합니다. 임의 자동 변환, 장음 생략 보정, 작은 っ 생략 보정은 하지 않습니다.
- 로마자 앞뒤 공백과 유니코드 조합 표현은 정규화하지만 내부 공백, 잘못된 철자, 다른 악센트는 임의로 고치지 않습니다. g a k k o u, gakk0u, gakkó는 오답입니다.
- 한국어 뜻과 히라가나 답안의 기존 비교 규칙은 유지했습니다.
- 학습 데이터 필드는 spelling / reading / meaning / romaji / acceptedRomaji로 분리했습니다. 허용 목록은 읽기 전용입니다.

## 정답 확인 화면

정답·오답 모두 왼쪽에 일본어 표기, 히라가나 읽기, 로마자 읽기, 한국어 뜻을 표시합니다. 학교는 허용 로마자 두 표기도 함께 안내합니다.

오른쪽에는 플레이어가 입력한 읽기와 뜻을 각각 표시하고, 읽기 정답/오답과 뜻 정답/오답을 나누어 보여 줍니다. 로마자로 맞혀도 히라가나가 사라지지 않습니다.

가나 전용 항목은 뜻만 입력받고, 채점 시 원래 가나 표기·히라가나·로마자·뜻을 표시합니다. 읽기는 '입력 대상 아님'으로 안내합니다. 실제 제공되는 테스트 단어는 여전히 学校·先生·本 세 개뿐입니다.

학습 → 문제풀이 → 채점 → 다음 단어 / 다시 학습 흐름과 교본 디자인은 유지했습니다. 문제풀이 중에는 정답 읽기·로마자·뜻을 표시하지 않습니다.

## 실제 검증 결과

헤드리스 Chromium에서 실제 게임 화면의 서당 입장, 이동 경로, F 대화, 수업 메뉴를 거쳐 학습 화면을 열었습니다.

- 33개 읽기·뜻 입력 조합 검증: 전부 통과. 세부 입력과 기대 판정은 verification-romaji/test-results.json 참조.
- 히라가나 정답, 허용 로마자 정답, 대소문자 혼합, 유니코드 조합형 장음 검증.
- 작은 っ 누락, 장음 누락, 잘못된 철자·악센트·내부 공백을 오답으로 판정.
- 읽기만 오답 / 뜻만 오답 / 둘 다 오답에서도 단어 정보 네 가지 및 실제 입력값과 개별 판정을 확인.
- 가나 전용 화면은 브라우저에서만 사용하는 임시 데이터로 검증: 뜻 입력칸 하나, 정답·오답 양쪽의 가나·로마자·뜻 표시 정상. 이 임시 데이터는 개발본 단어 배열에 추가하지 않았습니다.
- 다음 단어, 다시 학습, 세 단어 완료, 재시작, Esc 메뉴 복귀와 포커스 복원, 서당 퇴실 정상.
- 답안 입력 중 이동키가 캐릭터를 움직이지 않음. 한글/일본어 조합 중 Enter 및 조합 확정 직후 Enter 방지 유지.
- 390×844, 844×390 화면에서 가로 잘림 없이 입력·제출·결과 확인 가능.
- 수업 전후 기존 저장 스냅샷 동일.
- 테스트 브라우저 로컬 저장 후 새로고침 시 봉마편 6, 소지금 1234, 주먹밥 2, 씨앗/농산물, 던전·학습 기록 복원 확인.
- 브라우저 런타임 오류 없음.

## 보존 및 미확인 항목

변경된 기존 파일은 school/terakoya.js와 school/terakoya.css 두 개뿐입니다. 나머지 기존 파일 198개는 원본과 바이트 단위로 동일합니다. 메인 HTML, 에셋, 서당 배치/충돌, 게임 전투/농사/인벤토리 코드, 저장/클라우드 코드, 검색 제외 설정은 유지했습니다. 정식 GitHub Pages와 Firebase 프로젝트에는 변경 작업을 하지 않았습니다.

TTS, 오답노트 영구 저장, 전체 단어장 연결, 신규 보상은 추가하지 않았습니다. 임시 수업 데이터와 답안은 기존 개인 단어장에 등록하거나 영구 저장하지 않습니다.

실제 Google 로그인 및 Firestore 송수신, 모든 스테이지/EXTRA 완주와 모든 농사·상점 동작, 실제 휴대전화 IME, Windows 실행기는 이번 환경에서 재검증하지 않았습니다. 브라우저 검증은 외부 통신을 차단한 로컬 환경에서 진행했습니다.
