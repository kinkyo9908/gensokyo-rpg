# 케이네 서당 일본어 학습 UI 1차 개발본

정식 배포용이 아닌 별도 개발 복사본입니다. 최신 책장 배치 개발본을 기준으로 작업했습니다. 원본 ZIP은 수정하지 않았습니다.

## 실행 및 확인

1. 전체 ZIP을 새 폴더에 풀어 주세요. 기존 정식 게임 폴더에 덮어쓰지 않습니다.
2. Windows에서는 기존 `START_SCHOOL_DEV.bat`을 실행하고 콘솔을 켜 둡니다. 기존 개발 주소 `http://localhost:8896/`를 유지합니다. HTML 파일을 더블클릭하는 방식 대신 로컬 서버를 사용해 주세요.
3. 게임 시작 → 인간마을 중앙 → 서당 출입구 F → 교탁 옆 케이네에게 접근 → F.
4. 대화를 넘겨 수업 메뉴에서 **새로운 단어 배우기**를 선택합니다.
5. 학습 → 문제 풀기 → 읽기·뜻 입력 → 정답 확인 → 다음 단어.
6. 다시 학습 버튼으로 해당 단어로 돌아갈 수 있습니다. 세 번째 단어 이후 수업을 마치거나 처음부터 다시 시작할 수 있습니다.
7. 책의 **수업 메뉴로** 또는 Esc는 케이네 수업 메뉴로 돌아갑니다. 수업 메뉴에서 Esc를 누르면 대화를 종료합니다.

서버를 이미 실행 중이라면 기존 서버 콘솔을 종료한 뒤 이번 복사본에서 실행해 주세요. 브라우저의 로컬 저장소는 접속 주소별로 구분되며, 이 개발본은 기존 저장 키를 변경하거나 삭제하지 않습니다.

## 구현 범위

- 목재 표지 / 화지 색감 / 금색 테두리 / 붉은 책갈피의 실제 HTML·CSS 책 UI.
- 넓은 화면은 펼친 2페이지, 좁은 화면은 두 페이지를 세로로 읽는 스크롤 구성입니다.
- 学校 / がっこう / 학교, 先生 / せんせい / 선생님, 本 / ほん / 책의 세 임시 단어만 사용합니다.
- 표기·읽기·뜻·설명·예문·예문 번역은 별도 필드입니다.
- 학습 중에는 뜻과 읽기, 간단한 설명·예문을 표시합니다.
- 문제풀이로 바꾸면 학습 DOM을 제거하여 읽기·뜻·예문을 숨깁니다. 문제의 일본어 표기는 오른쪽에 표시됩니다.
- 한자가 포함되면 읽기와 뜻, 가나·가타카나만 있으면 뜻만 입력하는 분기를 마련했습니다. 이번 세 단어는 모두 한자 항목입니다.
- 시간제한은 없습니다. 빈 답안은 제출하지 않으며, 채점 후 올바른 답과 입력한 답을 비교할 수 있습니다.
- 한글/일본어 조합 입력과 Enter 확정 시 의도치 않은 제출을 방지합니다.
- 답안은 세션 메모리에서만 사용합니다. 개인 단어장 등록, 오답노트·진도 영구 저장, 보상, TTS는 없습니다.
- 다른 수업 메뉴는 기존 준비 중 안내를 유지합니다.

## 변경 파일 / 되돌리기

기존 파일의 변경은 **school/terakoya.js**, **school/terakoya.css** 두 개뿐입니다.
- JS: 기존 '새로운 단어 배우기' 선택지 연결, 책 모달 생명주기와 입력 차단, 독립적인 임시 수업 모듈.
- CSS: `.school-book-*` / `.lesson-*` 범위의 책 UI 스타일.
- 새 문서와 변경 전 백업만 추가했습니다.

`school/backup-before-lessons/`의 JS·CSS 두 파일을 원래 `school/`로 복사하면 이번 UI 추가를 되돌릴 수 있습니다. 학생·가구·케이네 이미지는 수정하지 않았습니다.

패치 ZIP은 **직전 책장 배치 개발본**의 게임 루트에 풀어 적용합니다. 기준이 다른 구버전에는 적용하지 않습니다. 전체 ZIP에는 게임 실행에 필요한 기존 에셋이 모두 포함됩니다.

## 보존 확인

원본 ZIP과 비교해 기존 파일 190개가 바이트 단위로 동일합니다. 메인 HTML, index.html, 에셋, 전투·단어 데이터, 저장 코드, cloud 폴더, noindex/nofollow 설정, 기존 실행기가 동일합니다.

서당 칠판·교탁·책장·학생 좌표, 충돌 및 깊이 정렬 설정은 변경하지 않았습니다. 정식 GitHub Pages와 Firebase 프로젝트에 쓰기/배포 작업을 하지 않았습니다.

## 실제 검증

헤드리스 Chromium에서 실제 게임 화면을 열고 다음을 확인했습니다.
- 인간마을 → 서당 출입, 교탁까지 경로 이동, F 대화와 수업 메뉴 진입.
- 학습 / 문제풀이 / 정답 / 오답 / 다시 학습 / 다음 단어 / 세 단어 완료 / 재시작.
- 문제풀이 중 정답 읽기·뜻·예문이 화면 DOM에 남지 않음.
- 입력칸에 F/W/A/S/D를 입력해도 캐릭터가 움직이지 않음.
- Enter 제출, 조합 입력 중 Enter 및 조합 확정 직후 Enter 방지, 빈 답안 제출 방지.
- Esc로 수업 메뉴 복귀 및 포커스 복원, 대화 종료 후 정상 서당 퇴실.
- 1440×1000, 390×844, 844×390 화면의 스크롤·입력·제출. 가로 잘림 없음.
- 가나·가타카나 뜻만 묻는 판정은 별도 순수 함수 테스트로 검증. 실제 임시 단어는 세 개만 유지.
- 수업 전후 기존 저장 스냅샷이 동일함.
- 테스트 브라우저의 로컬 저장 후 새로고침에서 봉마편 6, 소지금 1234, 주먹밥 2, 씨앗·농산물 및 기존 던전·학습 데이터 복원.
- 브라우저 런타임 오류 없음.

## 미확인

실제 Google 로그인 / Firestore 송수신, 모든 스테이지·EXTRA 완주, 모든 농사·상점 동작, 실제 휴대전화 키보드, Windows 실행기는 이번 환경에서 재검증하지 않았습니다. 해당 코드와 리소스는 변경하지 않았습니다. 자동 브라우저 검증에서는 외부 통신을 차단했으며 실제 사용자 계정을 사용하지 않았습니다.
