# 서당 v4 — 제1권 실제 첫10개 학습

이번 개발본의 최신 안내입니다. 이전 README/조사 보고서는 과거 단계 기록으로 보존했습니다.

## 실행

1. 전체 ZIP을 새 폴더에 풉니다. 정식 게임 폴더에 덮어쓰지 않습니다.
2. 이전 개발 서버가 열려 있다면 해당 콘솔을 종료합니다.
3. `START_SCHOOL_DEV.bat`을 실행합니다. 기존 개발 주소 `http://localhost:8896/`와 저장 키를 유지합니다.
4. 인간마을 → 서당 입구 F → 케이네 F → 새로운 학습 → 환상향 단어장 → 제1권.
5. **학습 시작 · 실제 1~10번**을 누르면 評価부터 시작합니다.
6. 学校·先生·本은 별도의 **기존 3단어 UI 테스트** 버튼으로 열 수 있습니다.
7. 학습 → 문제풀이 → 채점 → 다음 단어를 진행합니다. 10번째 距離 이후 수업 마치기로 종료합니다.
8. Esc 또는 책장으로 버튼은 책장으로 돌아갑니다. 책장에서 Esc는 케이네 수업 메뉴로, 다시 Esc는 게임으로 돌아갑니다.

## 이번 범위

전투용101개를 제1권 기준으로 확정했고, 실제 학습 자료에는 원래 순서의 첫10개만 연결했습니다. 나머지91개는 이번 학습 자료에 넣지 않았습니다. 기존106개 `level1Words`, 그 ID와 학습 기록은 변경하지 않았습니다.

첫10개: 評価 / 客 / 入学 / 注意 / 料理 / 会社 / お茶 / 修理 / 物価 / 距離.

설명·예문은 원본에 없으므로 미등록으로 두었습니다. 학습 화면의 해당 블록은 생략되며, 나중에 승인된 설명/예문을 자료에 추가할 수 있습니다. 한글 뜻과 복수 읽기는 배열로 보존하고 개별 허용 답안으로 판정합니다.

로마자는 히라가나에서 엄격한 음절 변환으로 생성합니다. 전투의 로마자 별칭은 복사하지 않습니다. 실제 범위의 허용 표기와 판정 결과는 `VOLUME1_FIRST10_REPORT.md`를 확인해 주세요.

자료의 순번·필수 값·읽기가 지원되지 않는 경우 실제 학습을 차단하고 오류 안내를 표시합니다. 임의로 단어를 생성하거나 잘못된 항목을 건너뛰지 않습니다.

## 파일 변경

기존 파일 중 변경:
- `school/terakoya.js`: 실제 수업 자료 로딩, 제1권 실제/3단어 테스트 분리, 배열 답안 처리, 엄격한 로마자 변환, 선택적 설명·예문.
- `school/terakoya.css`: 미등록 정보와 버튼 간격, 책 UI의 일본어 보조 글꼴 범위.

추가:
- `school/volume1-words.json`: 원본 첫10개, 전체101개/활성10개 메타데이터.
- `school/assets/lesson-jp.woff`: 운영체제별 일본어 글꼴 차이에 대응하는 약100KB 로컬 서브셋.
- `school/assets/lesson-jp-OFL.txt`: 해당 글꼴의 라이선스.
- `school/backup-before-volume1/`: 이번 변경 직전 v3의 JS·CSS.
- 이번 안내·결과 보고서, `verification-volume1/`의 원본 대조/자동 테스트 결과.

패치 ZIP은 **직전 서당 v3 책장 개발본**의 게임 루트에 적용합니다. 전체 ZIP은 그대로 새 폴더에서 실행할 수 있습니다.

## 복구

`school/backup-before-volume1/`의 JS·CSS를 원래 `school/`로 복사하면 v3 책장 개발본으로 돌아갑니다. 이번에 추가된 JSON과 글꼴은 v3 코드에서 사용하지 않으므로 남아 있어도 저장 데이터에 영향을 주지 않습니다. 원본 v3 ZIP도 보존했습니다.
