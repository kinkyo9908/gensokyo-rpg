# 케이네 서당 2차 — 최종 승인 리소스 적용 개발본

최신 서당 2차 개발본에 2026-10-17 제공 ZIP의 PNG 3장을 적용했습니다.
정식 GitHub Pages에 업로드하지 않은 별도 복사본입니다.
첨부 지시서: school/README_APPROVED_ASSETS.txt
최신 테스트: school/FINAL_TEST_RESULTS.json, FINAL_FILE_VERIFICATION.json
기존 README_SCHOOL_PHASE2.md와 PHASE2_* 결과는 교체 전 개발 과정의 기록입니다.

## 실행 및 화면 확인
1. 전체 ZIP을 새 폴더에 압축 해제합니다. HTML만 분리하지 마세요.
2. 이전 서당 개발 서버가 실행 중이면 해당 창을 닫습니다.
3. START_SCHOOL_DEV.bat 실행. 개발 주소 localhost:8896을 그대로 사용합니다.
4. '인간마을 중앙'에서 시작하여 서당 입구에 접근, F키로 입장합니다.
5. 교탁 오른쪽 케이네에게 접근해 F키를 누릅니다.
   첫 인사는 기본 표정, 다음 인사 및 수업 메뉴는 웃는 표정입니다.
6. 업데이트 이전 이미지가 보이면 Ctrl+F5. 로컬 저장을 삭제할 필요는 없습니다.

## 변경 사항
- school/assets/keine_map.png: 제공한 1254×1254 원본 그대로 적용.
- school/assets/keine_dialogue_normal.png: 제공한 1024×1536 원본 그대로 적용.
- school/assets/keine_dialogue_smile.png: 제공한 1024×1536 원본 그대로 적용.
- 3개 PNG는 첨부 ZIP과 SHA-256 및 실제 바이트가 동일합니다.
- 기존 JS/CSS의 same-size contain 배치를 그대로 재사용합니다.
  기본·웃는 초상화에 개별 크롭이나 상이한 확대 배율을 적용하지 않았습니다.
- 케이네는 이전 2차 개발본의 교탁 오른쪽 위치와 높이를 유지합니다.
- 학생/책상/의자/교탁/책장/판서판/배경/출입구/충돌/가림 처리 변경 없음.
- 기존 4개 수업 메뉴와 종료 선택지를 그대로 유지합니다.
  실제 학습 전체 기능을 추가하는 작업은 이번 범위에 포함하지 않았습니다.

## 투명도 검사 결과 — 원본 수정 없음
PNG 3개 모두 실제 알파 채널이 있으며 사각 배경/체커보드는 게임 화면에 나타나지 않습니다.
실제 교실의 밝은 목재 벽과 어두운 주변 영역 위에서 초상화를 직접 확인했습니다.
머리카락 외곽 일부에 가느다란 청색/청보라 계열 픽셀이 남아 있습니다.
특히 앞머리 외곽과 양옆으로 뻗은 머리카락 끝 부분에서 보이며,
어두운 배경과 확대 상태에서 더 쉽게 식별됩니다. 배경 전체가 남은 형태는 아닙니다.
이는 원본에도 포함된 외곽 픽셀입니다. ZIP 지시에 따라 제거하거나 재렌더링하지 않았습니다.
두 초상화는 같은 프레임으로 표시되지만 원본 내 미세한 픽셀 차이는 그대로 유지합니다.

## 실제 확인한 항목
로컬 Chromium 153에서 PC 1440×1000, 모바일 크기 390×844로 확인했습니다.
- 실제 F키로 인간마을 → 서당 입장 및 서당 → 인간마을 퇴장
- 신규 케이네 지도 이미지 및 기본/웃는 초상화 출력
- 기본/웃는 상태의 화면 표시 영역 좌표·크기 동일
- 초상화 원본 전체 contain 표시, 화면 가장자리 및 대화창에 잘리지 않음
- 기본 인사 → 웃는 인사 → 수업 메뉴 진행
- 4개 학습 항목+종료 1개 표시, 마우스 선택 및 키보드 진행/종료
- 모바일에서 5개 선택지 모두 화면 내 표시
- 학생 포함 주민 수 5명, 중앙 통로·케이네 접근 경로 유효, 책상 4개 충돌 유지
- 다른 NPC 미요이의 기존 대화 메뉴 정상 유지
- 서당 상호작용 전후 저장 스냅샷 동일
- 별도 테스트 브라우저에서 봉마편 6/전 1234/주먹밥 2/
  감자 씨앗 3/당근 수확물 4/유진 만남 기록을 저장하고 새로고침한 뒤 복원 일치
- 이전 대화창 배치로 되돌리는 토글 정상 작동
- 페이지 JavaScript 오류 0건
- 이전 개발본 기존 파일 159개 비교: 기존 코드/HTML/CSS/배경/게임 에셋 그대로,
  케이네 PNG 3장만 교체. 추가 파일은 지시서/백업/이 문서/최신 테스트 결과입니다.
