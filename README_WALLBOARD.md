# 케이네 서당 — 새 벽걸이형 칠판 적용 개발본

기준: 직전 가구 이동을 취소한 gensokyo_rpg_school_restored_dev.
정식 GitHub Pages/Firebase 설정을 변경하지 않은 별도 개발 복사본입니다.
최신 설명은 본 문서와 school/WALLBOARD_* 파일을 확인하세요.
이전 README와 LAYOUT/FINAL/RESTORE 결과는 해당 시점의 이력입니다.

## 적용 자산 및 변경 파일
- school/assets/blackboard-wall.png
  첨부 '이소메트릭 칠판과 보라색 술 장식(1).png'를 파일 바이트 그대로 복사했습니다.
  1448×1086 RGBA. 재생성/색상 수정/회전/비틀기/원근 왜곡/원본 크롭 없음.
- school/terakoya.js
  새 PNG 프리로드, 기존 칠판 표시 등록 제거, 벽면 기준의 새 칠판 표시 등록.
- school/terakoya.before-wallboard.js
  교체 직전 전체 스크립트 백업. 원래 스탠드형 칠판으로 복귀할 때 사용합니다.
- 본 문서 및 school/WALLBOARD_TEST_RESULTS.json / WALLBOARD_FILE_VERIFICATION.json

기존 아틀라스에 있는 구형 칠판 그림은 공유 리소스 보존을 위해 남아 있지만
화면 표시 등록에서는 제외했습니다. 새 칠판은 정확히 1개만 등록됩니다.

## 벽면 접점과 깊이
기존 하단 중앙/바닥 가구 좌표를 재사용하지 않았습니다.
새 PNG 상단 왼쪽 블록의 뒤쪽 접점인 원본 좌표 (280,110)을 기준으로,
교실 그림의 오른쪽 뒤 벽면 좌표 (920,220)에 맞췄습니다.
PNG 전체 캔버스를 가로세로 동일 배율 0.25로 표시합니다.
실제 칠판 프레임의 알파 영역 폭은 약 275 게임 단위이며,
불필요한 캔버스 여백을 프레임 크기로 오인해 확대하지 않았습니다.

벽과 칠판의 긴 모서리가 모두 오른쪽 아래로 내려가는 방향임을 확인했습니다.
각 원본의 세부 기울기를 강제로 일치시키는 회전/비틀기는 적용하지 않았습니다.
크기와 벽면 접점만 조절해 원본 모습을 유지했습니다.
칠판의 최종 배치는 하단 프레임과 바닥 사이에 여유가 있도록 했습니다.

벽걸이 칠판은 기존 깊이 큐의 가장 뒤쪽에 등록해 바닥 가구/캐릭터보다 먼저 그립니다.
벽면 표시 위치와 바닥 접점의 깊이가 섞이지 않도록 분리한 것입니다.
기존 공통 렌더 루프와 다른 맵의 깊이 규칙은 수정하지 않았습니다.

벽 접촉 그림자는 동일 PNG 알파를 사용한 짧은 그림자 1회입니다.
오프셋 1.5 게임 단위, 불투명도 12%, 흐림 없음.
게임 캔버스의 보조 효과이며 PNG 파일 픽셀을 변경하지 않습니다.

## 투명도 및 외곽
실제 알파 채널이 있으며 체커보드/사각 배경은 게임에 나타나지 않습니다.
PNG 바깥쪽에 알파 1~8의 매우 희미한 잔여 픽셀이 일부 있습니다.
주요 칠판의 알파 8 초과 범위는 원본 좌표 (178,67)~(1279,1044)입니다.
원본을 그대로 사용하라는 요청에 따라 잔여 픽셀을 지우지 않았습니다.
실제 게임과 2배 확대 비교 화면에서 외곽 및 접촉 그림자를 확인했습니다.

## 유지한 배치와 기능
교탁, 큰 책장, 학생 4명과 책상, 케이네 위치·리소스·초상화,
출입구, 충돌, 가림 폴리곤은 교체 전/후 데이터 비교로 동일함을 확인했습니다.
책장은 이번 단계에서 이동하지 않았습니다.
작은 책장이 이미 제거된 복구본의 상태도 그대로입니다.
배경, 벽/바닥/기둥/창문/햇빛, 카메라, CSS 및 중앙 대화창을 바꾸지 않았습니다.
새 일본어 학습 시스템은 추가하지 않았고 기존 준비용 메뉴를 유지했습니다.

## 실제 테스트
로컬 Chromium, 1440×1000에서 실제 게임을 실행했습니다.
- 복구본과 교체본 전체 화면을 같은 시작 위치에서 촬영
- 칠판을 제외한 주민/상호작용/충돌/가림/가구 데이터 전후 일치
- 새 칠판 1개 등록, 구형 칠판 표시 등록 0개
- 칠판이 캐릭터보다 뒤쪽 레이어에서 표시됨
- F키 인간마을 → 서당 입장
- 입구에서 케이네까지 실제 경로 이동 및 F키 대화
- 기본/웃는 표정의 표시 영역 동일, 기존 수업 메뉴 4개+종료 유지
- 수업 선택 시 기존 준비 안내 정상 표시
- 교탁/학생 책상 충돌과 중앙 통로, 케이네 접근 지점 정상
- 인벤토리 열기/닫기
- 케이네 근처에서 출구까지 실제 경로 이동 후 F키 퇴장
- 서당 상호작용 전후 저장 스냅샷 동일
- 테스트 저장: 봉마편 6/전 1234/주먹밥 2/감자 씨앗 3/당근 수확물 4의 새로고침 복원 일치
- 페이지 오류 0건

기준본 기존 파일 181개 비교에서 기존 파일 중 school/terakoya.js만 변경됐습니다.
신규 PNG는 첨부 이미지와 SHA-256 및 실제 파일 바이트가 동일합니다.
기존 이미지/CSS/HTML/클라우드 파일은 동일합니다.
실제 Google 로그인/Firestore 동기화와 모든 스테이지/EXTRA 완주,
실제 Windows 실행기 및 휴대전화는 이번 변경에서 재시험하지 않았습니다.
사용자의 실제 로컬/클라우드 기록은 읽거나 변경하지 않았습니다.

## 실행/패치/복원
전체 ZIP을 새 폴더에 모두 압축 해제하고 START_SCHOOL_DEV.bat 실행.
이전 개발 서버 창이 열려 있다면 닫습니다. 기존 localhost:8896 주소를 유지합니다.
인간마을 중앙에서 시작해 서당 입구에서 F키로 입장합니다.
이전 칠판이 남으면 Ctrl+F5. 저장 데이터를 삭제하지 마세요.

패치 ZIP은 직전 '복구한 서당 개발본'의 루트 폴더에 덮어쓰는 용도입니다.
서당이 없는 정식 배포본에는 패치만 적용하지 마세요.

원래 칠판으로 돌아가려면 school/terakoya.before-wallboard.js를
school/terakoya.js 위에 복사합니다. 새 PNG는 남겨도 더 이상 참조되지 않습니다.
다른 가구나 저장 데이터를 되돌릴 필요는 없습니다.
