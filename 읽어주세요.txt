환상향 RPG v80 — 메모리 개선판

1. ZIP 전체를 새 폴더에 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
2. START_GAME.bat을 더블클릭합니다. Windows 기본 PowerShell을 사용하므로 Python 설치는 필요하지 않습니다.
3. 브라우저가 열리면 저장 기록을 먼저 가져오거나, 환상향으로 출발을 선택합니다.
4. 플레이 중에는 실행창을 닫지 마세요. 종료할 때 게임을 닫고 실행창도 닫습니다.
5. 매번 같은 브라우저와 http://127.0.0.1:8765/ 주소로 실행합니다. 시크릿 모드는 사용하지 마세요.

기존 저장 기록 옮기기 (중요)
새 실행 주소는 이전 HTML 파일 주소와 다릅니다. 기록이 자동으로 이동하지 않습니다.
브라우저 데이터, 기존 게임 파일 및 기존 폴더를 삭제하지 마세요.

A. 기존 게임이 시작되지 않을 때
1. 기존 게임 HTML을 보관용 폴더에 복사해 백업합니다. 원래 폴더 위치와 정확한 파일명을 기록해둡니다.
2. 원래 폴더의 기존 게임 HTML은 잠시 보관용 이름으로 바꿉니다.
3. 이 패키지의 SAVE_RESCUE.html을 원래 게임 폴더에 복사합니다.
4. 복사한 SAVE_RESCUE.html의 파일명을 원래 게임의 정확한 파일명으로 바꿉니다.
   예: 원래 실행한 파일이 gensokyo_rpg_integrated_v79.html이었다면 바로 그 이름을 사용합니다.
   Windows에서 파일 확장명 표시를 켜고 .html이 두 번 붙지 않았는지 확인하세요.
5. 예전에 게임을 하던 동일한 브라우저·프로필에서 이 작은 복구 HTML을 엽니다.
6. '기존 저장 기록 내보내기'를 눌러 JSON 백업을 받습니다.
7. 새 v80의 START_GAME.bat으로 연 시작 화면에서 JSON을 가져온 뒤 게임을 시작합니다.
8. 기존 HTML 백업은 그대로 보관합니다. 원래 폴더의 이름 변경을 되돌려도 괜찮습니다.

찾지 못했다고 나오는 경우
file:// 저장 영역은 브라우저가 파일 경로별로 다르게 처리할 수 있습니다. 복구 도구는 기록을 찾았다고 표시한 경우에만 내보냅니다.
원래 사용한 정확한 파일 경로, 파일명, 브라우저 프로필을 확인하세요. 예전 작업 파일에서 플레이한 기록은 그 파일의 경로에서 같은 절차로 찾을 수 있습니다.
기존 파일을 localhost 웹 서버에서 실행했다면, 그때와 같은 주소·포트에 복구 페이지를 두어야 합니다.
그동안 브라우저 기록/사이트 데이터를 이미 삭제했다면 이 도구만으로 복구할 수는 없습니다.

B. 새 버전에서 기록 백업
시작 화면의 '현재 기록 백업'으로 JSON을 저장할 수 있습니다. 가져오기 시 이미 기록이 있으면 확인창이 뜨고 현재 기록도 먼저 내려받습니다.

실행 관련
- assets 폴더와 모든 파일을 함께 유지합니다. HTML만 따로 옮기면 이미지/음악이 표시되지 않습니다.
- 포트 8765가 사용 중이면 이전 게임 실행창을 닫고 다시 실행합니다. 임의로 포트를 변경하면 저장 주소가 달라집니다.
- 이 서버는 내 컴퓨터(127.0.0.1)에만 연결됩니다. 외부에 게임을 게시하지 않습니다.
- Windows/Chrome 실제 환경의 실행은 이 작업 환경에서 직접 확인하지 못했습니다. 오류가 계속되면 실행창의 문구와 브라우저 오류를 알려주세요.

변경 내용
- 284,391,155바이트 단일 HTML의 이미지/음악/글꼴 126개를 외부 파일로 분리했습니다. 시작 HTML은 940,198바이트입니다.
- 이미지는 다시 생성하거나 축소하지 않았으며 음악도 원본 바이트를 보존했습니다.
- Blob 전투 화면에 원래 게임 주소를 기준 경로로 지정하여 분리된 에셋을 사용합니다.
- 전투, 문제, 보상, 농사, NPC 및 기존 저장 스키마는 변경하지 않았습니다.
- 원본 v79는 보존했습니다.
