# 케이네 서당 v3 — 책장 선택 UI

최신 v2 로마자 입력 개발본을 복사해 작업했습니다. 정식 GitHub Pages는 수정하지 않았습니다.

## 실행

1. 전체 ZIP을 새 폴더에 풉니다. 정식 게임 폴더에는 덮어쓰지 않습니다.
2. `START_SCHOOL_DEV.bat`을 실행합니다. 기존 개발 주소 `http://localhost:8896/`를 유지합니다.
3. 인간마을 → 서당 입구 F → 교탁 근처 케이네 F → 대화 → **새로운 학습**.
4. **환상향 단어장** 책장에서 권을 선택합니다. 현재 등록된 실제 권은 제1~5권입니다.
5. **학습 시작 · 3단어 테스트**를 누르면 기존 学校·先生·本 학습 화면으로 이동합니다.
6. 학습 → 문제풀이 → 채점 → 다음 단어를 사용할 수 있습니다.
7. 학습 화면의 **책장으로** 또는 Esc는 책장으로 돌아갑니다. 책장의 **수업 메뉴로** 또는 Esc는 케이네 수업 메뉴로 돌아갑니다. 그 상태에서 Esc를 누르면 대화를 종료합니다.

이전 개발 서버가 실행 중이면 해당 콘솔을 종료한 후 이번 복사본에서 실행해 주세요. HTML 직접 실행 대신 로컬 서버를 사용합니다.

## 책장 기능

- 등록 목록에서 한 번에10권씩만 렌더링합니다. 현재5권이므로 나머지는 빈 자리로 표시하고, 다음 책장 버튼은 비활성화합니다. 미등록 권을 실제 책처럼 만들지 않습니다.
- 이전/다음 책장, 권수 직접 입력, 선택한 권의 항목 수·관련 스테이지·학습 상태 및 학습 시작 버튼.
- 넓은 화면은10칸 가로 책장, 좁은 화면은5칸씩2줄이며 나머지 정보는 스크롤로 확인합니다.
- 명칭은 환상향 단어장 / 제N권을 사용합니다.
- `school/bookshelf-catalog.json`에 새 권의 `number`, `wordCount`, `stageId`를 등록하면 화면 코드를 수정하지 않아도 표시됩니다. 번호가 비어 있는 경우에도 직접 이동은 실제 등록된 권만 허용합니다.
- 100권 목록은 자동 테스트에서만 사용했으며 실제 배포 파일에는5권만 등록했습니다.

## 진도 표시 준비

`unlearned`(미학습), `in_progress`(진행 중), `completed`(학습 완료)의 표시 구조와 읽기 전용 연결부를 준비했습니다. 실제 저장 기록은 연결하지 않았습니다. 기본 상태는 미학습이며, 서당 진도 미연결임을 화면에서 안내합니다. 전투 기록이나 세 단어 테스트 완료를 실제 권 학습 완료로 간주하지 않습니다.

`GensokyoLessonBook.setProgressReader(reader)`는 향후 확인된 진도 기록을 읽기만 하는 어댑터 연결 지점입니다. 현재 기본 reader는 null을 반환합니다. 테스트에서 주입한 진행 중/완료 레코드는 브라우저 메모리에서만 사용했고 파일이나 로컬/클라우드 저장에는 기록하지 않았습니다.

## 전체 단어장 연결 보류

어느 권을 선택해도 현재 학습 시작은 **공통3단어 UI 테스트**입니다. 해당 권의 실제 전체 단어가 학습 화면에 들어오는 것이 아닙니다. 실제 단어 수만 확인된 메타데이터로 표시합니다.

별도 조사 보고서 `WORD_DATA_AUDIT.md`를 확인해 주세요. 전투용5권 총450개와 기존 학습 기록용106개 데이터는 구조와 항목 구분이 다르고, 제1권의 ID 매핑 및 로마자 허용 정책을 먼저 정해야 합니다. 이번에는 기존 단어 데이터를 수정하거나 누락분을 추측하지 않았습니다.

## 테스트 결과

실제 헤드리스 Chromium 게임 화면에서 다음을 확인했습니다.

- 마을에서 서당 출입, 경로 이동, F 대화, 새로운 학습 → 책장 진입.
- 실제5권·빈 자리5개, 권별 실제 항목 수 표시, 기본 미학습 상태.
- 권 선택 및 번호 직접 이동, 0·소수·미등록 권 입력 오류 안내.
- 메모리용100권 목록: 매 페이지10개만 렌더링, 이전/다음, 제100권 이동과 마지막 페이지 경계.
- 진도 상태 연결부에 테스트용 기록을 주입했을 때 세 상태를 구분하고, 연결 해제 후 임의 완료가 남지 않음.
- 실제 제1~5권 각각에서 기존 세 단어 테스트로 진입.
- v2의 읽기·뜻 입력33개 조합, 히라가나·로마자 정답 및 잘못된 장음/작은っ 누락 오답 검증 유지.
- 가나 전용 입력·채점 분기는 브라우저 임시 데이터로 검증. 실제 제공 단어는3개 그대로 유지.
- 다음 단어/다시 학습/완료/재시작, 문제풀이 중 정답 숨김.
- 입력 중 이동 차단, IME Enter 방지, Esc 단계 복귀와 메뉴 포커스 복원.
- 390×844, 844×390 화면에서 책장·직접 이동·학습·채점의 가로 잘림 없음.
- 수업 전후 저장 스냅샷 동일, 로컬 저장 후 재실행에서 재화·주먹밥·씨앗·농산물·던전·학습 데이터 유지.
- 브라우저 런타임 오류 없음.

세부 자동 테스트 결과: `verification-bookshelf/test-results.json`.

미확인: 실제 Google 로그인/Firestore 송수신, 모든 스테이지와 EXTRA 완주, 모든 농사·상점 동작, 실제 휴대전화 키보드 및 Windows 실행기. 관련 원본 코드와 리소스는 보존했습니다.
