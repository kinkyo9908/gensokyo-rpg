# 뒤쪽 큰 책장 위치만 미세조정한 서당 개발본

기준: 새 벽걸이형 칠판을 적용한 gensokyo_rpg_school_wallboard_dev.
정식 GitHub Pages는 수정하지 않은 별도 개발 복사본입니다.
기존 문서는 이전 개발 이력이며 최신 조정/검증은 본 문서와 school/SHELF_* 파일을 확인하세요.

## 변경 범위
school/terakoya.js에서 아래 좌표 2곳만 변경했습니다.
- 큰 책장 표시 u/v: 80/125 → 68/48
- 큰 책장 충돌 중심 u/v: 80/145 → 68/68

화면 배치에 쓰는 교실 좌표로는 x=690.760,y=391.815에서
x=725.516,y=366.808로 이동했습니다. 오른쪽 약 34.8, 위쪽 약 25.0 게임 좌표입니다.
실제 표시 픽셀 이동량은 화면 크기와 기존 카메라 배율에 따라 달라집니다.
표시 폭 113, 이미지 비율, 원래 책장 그림, 그리기 함수는 동일합니다.
기존 addProp()이 새 위치의 Y값을 깊이 값으로 사용하므로 깊이 정렬도 함께 이동합니다.
기존 충돌과 이미지 사이의 v축 간격 20도 유지했습니다.

참고 이미지 '햇살 머무는 아늑한 책장 모퉁이(1).png'는 배치 의도만 확인했습니다.
이 그림을 새 배경/책장 리소스로 복사하거나 사용하지 않았습니다.
기존 classroom-atlas.png의 동일한 책장 영역을 계속 사용합니다.
새 이미지, 새 그림자, 회전, 크기 조정, 색상 변경을 하지 않았습니다.

## 바닥 접점 확인
기존 스프라이트의 하단 중앙만 위로 밀지 않고,
그림에 보이는 앞쪽 발과 오른쪽 뒤 모서리를 실제 교실의 벽–바닥 경계와 비교했습니다.
책장의 보이는 하단 모서리가 바닥 쪽에 남도록 여유를 두었고,
창틀/벽 기둥에 바닥이 파묻히지 않는지 전체 및 확대 화면에서 확인했습니다.
현재 이미지는 고정된 배치이므로 실제 게임 화면 기준의 접점 확인입니다.
배경을 분석하는 새 벽면/3D 물리 시스템을 추가하지 않았습니다.

## 그대로 유지한 요소
칠판(새 벽걸이형), 교탁, 학생 4명/책상/의자, 케이네의 위치/도트/초상화,
출입구, 대화/수업 메뉴, 카메라, 바닥/벽/창문/햇빛, 기존 가림 처리 모두 유지했습니다.
다른 가구의 충돌 영역도 그대로입니다.
책장을 제외한 가구/주민/상호작용/지형 데이터가 전후 동일함을 실제 브라우저에서 비교했습니다.
게임 본체, 전투/EXTRA/농사/인벤토리, 로컬/클라우드 저장 키와 스키마,
Firebase 관련 코드, 기존 CSS와 모든 이미지 파일은 변경하지 않았습니다.
새 일본어 학습 기능을 추가하지 않았습니다.

## 실제 확인한 테스트
로컬 Chromium, 1440×1000에서 확인했습니다.
- 책장 이외의 배치 및 상호작용/충돌/가림 데이터 전후 동일
- 책장 폭 113 유지, 새 Y 좌표와 깊이 정렬값 일치
- 책장 이동 후 예전 충돌 자리 일부가 이동 가능해짐
- 새 책장 위치의 충돌 유지
- 실제 F키로 서당 입장
- 입구 → 케이네 실제 경로 이동, F키 대화
- 기존 기본/웃는 초상화 및 동일한 표시 영역 유지
- 4개 수업+종료 메뉴 유지, 준비 안내 정상
- 인벤토리 열기/닫기
- 케이네 근처 → 출구 실제 경로 이동 및 F키 퇴장
- 상호작용 전후 저장 스냅샷 동일
- 봉마편 6/전 1234/주먹밥 2/감자 씨앗 3/당근 수확물 4를 포함한
  별도 테스트 브라우저의 로컬 저장이 새로고침 후 동일하게 복원됨
- 페이지 스크립트 오류 0건

실제 Google 로그인/Firestore 동기화와 모든 스테이지/EXTRA 완주는 재시험하지 않았습니다.
관련 파일은 변경하지 않았고 사용자의 실제 로컬/클라우드 기록에 접근하지 않았습니다.

## 실행과 복구
전체 ZIP을 새 폴더에 모두 압축 해제하고 START_SCHOOL_DEV.bat 실행.
이전 개발 서버 창이 열려 있으면 먼저 닫습니다. localhost:8896 주소는 동일합니다.
인간마을 중앙에서 시작 후 서당 입구에서 F키로 입장합니다.
이전 위치가 남아 보이면 Ctrl+F5로 새로고침하며 저장 데이터를 삭제하지 마세요.

패치 ZIP은 직전 벽걸이 칠판 적용 개발본 루트에 덮어쓰는 용도입니다.
책장 이동 전으로 되돌리려면 school/terakoya.before-shelf.js를 school/terakoya.js 위에 복사합니다.
다른 리소스나 저장 데이터를 바꿀 필요는 없습니다.
