# 케이네의 서당 2차 개발본

정식 GitHub Pages에는 업로드하지 않은 독립 개발 복사본입니다.
기준: 학생·책상 비율을 개선한 school visual v2 개발본.

## 실행
1. ZIP 전체를 새 폴더에 압축 해제합니다. HTML만 꺼내지 마세요.
2. 이전 서당 테스트 서버 창이 열려 있으면 닫습니다.
3. START_SCHOOL_DEV.bat를 실행합니다. 기존 localhost:8896 개발 주소를 사용합니다.
4. 시작 위치 '인간마을 중앙'을 선택하고 서당 입구에서 F키로 입장합니다.
5. 교탁 오른쪽 케이네에게 접근해 F키를 누릅니다.
   첫 인사는 기본 표정, 다음 인사와 수업 메뉴는 웃는 표정입니다.
   수업 항목은 기존과 동일한 준비용 메뉴이며 학습 기능을 새로 구현하지 않았습니다.
캐시가 남아 있으면 Ctrl+F5를 사용합니다. 저장 데이터를 삭제하지 마세요.

## 변경 파일
- school/terakoya.js: 학교 케이네만 신규 PNG 사용. 교탁 옆 위치 소폭 조정.
  원본 아틀라스와 기존 NPC는 유지. 기본/웃는 초상화 전환, 서당 전용 배치 토글 추가.
- school/terakoya.css: 서당 대화만 플레이어 왼쪽·케이네 오른쪽·중앙 하단 창 적용.
  머리·손·소매가 화면 밖으로 잘리지 않도록 contain 및 안전 여백 적용.
  일반 선택지 4개와 종료 1개를 그대로 유지. 작은 화면에서는 창 내부 스크롤 가능.
- school/assets/keine_map.png, keine_dialogue_normal.png, keine_dialogue_smile.png:
  사용자 첨부 원본을 바이트 그대로 복사. 이미지 재생성·크롭·색상 수정 없음.
  3개 모두 RGBA 투명 배경 확인. 지도 이미지만 실제 알파 경계를 렌더링 크기에 사용.
- school/rollback/terakoya.js, terakoya.css: 변경 전 두 파일의 원본 백업.
- school/PHASE2_TEST_RESULTS.json, PHASE2_FILE_VERIFICATION.json: 실제 확인 결과.

## 배치
지도 케이네는 실제 머리~발 높이 126 게임 단위로 표시합니다.
기존 (u820,v120)에서 (u790,v125)로 소폭 이동하며 교탁은 유지했습니다.
학생 4명, 학생 책상 4개, 책·의자, 벽·바닥·판서판·창문은 변경하지 않았습니다.
중앙 이동 통로와 케이네 접근 경로가 유효하여 책장 위치도 유지했습니다.
초상화 2장은 원본 475×766 전체를 같은 고정 영역에 contain으로 표시합니다.
초상화 원본의 자세 차이는 그대로 유지하며 비율이나 픽셀을 변형하지 않습니다.

## 쉽게 되돌리기
새 이미지를 유지하면서 대화창 배치만 되돌리려면 school/terakoya.js의
state 선언에 있는 experimentalDialogue:true 를 experimentalDialogue:false 로 바꿉니다.
다시 true로 바꾸면 새 배치가 적용됩니다. 저장 키나 저장 데이터에는 기록하지 않습니다.
일시 비교는 브라우저 개발자 콘솔에서 다음 호출도 가능합니다.
GensokyoSchool.setDialogueLayout('legacy')
GensokyoSchool.setDialogueLayout('trial')

2차 변경 전체를 이전 서당 상태로 되돌리려면 school/rollback 안의
terakoya.js와 terakoya.css를 school 폴더의 동명 파일 위에 복사합니다.
추가 PNG는 그 상태에서 참조되지 않으며, 삭제할 필요는 없습니다.
기준 전체 ZIP도 별도로 보존되어 있습니다.

## 실제 확인
로컬 Chromium 153, 1440×1000 및 390×844에서 확인했습니다.
- 마을에서 F키로 서당 입장 / F키 퇴장
- 케이네 신규 지도 PNG 및 기본·웃는 초상화 출력
- 기본/웃는 표정의 표시 영역 좌표·크기 완전 동일
- 원본 전체 contain, 초상화 화면 좌우 및 대화창 가림 없음
- 4개 수업+종료 메뉴, 키보드 진행·종료, 마우스 선택
- 모바일에서 5개 선택지 모두 화면 안에 표시
- 책상 4개 충돌, 중앙 통로 및 케이네 접근 경로 유효
- 다른 NPC(미요이) 기존 메뉴 유지, 서당 배치 클래스 종료 시 제거
- 서당 상호작용 전후 원래 저장 스냅샷 불변
- 테스트 저장: 봉마편 6 / 전 1234 / 주먹밥 2 / 감자 씨앗 3 /
  당근 수확물 4 / 유진 만남 기록을 넣은 로컬 저장의 새로고침 복원 일치
- 화면 배치 legacy/trial 전환 정상, 페이지 스크립트 오류 0건
- 기준본 151개 기존 파일 비교: JS/CSS 2개만 변경.
  gensokyo_rpg.html, index.html, cloud 코드와 기존 assets 모두 바이트 동일.

## 미확인 범위
이번 변경본에서 실제 Google 로그인·Firestore 업로드/다운로드는 재시험하지 않았습니다.
실제 Windows 실행기와 휴대전화 하드웨어에서도 별도 확인이 필요합니다.

전투·농사·인벤토리·저장·Firebase·검색 제외 설정을 담은 기존 파일은 수정하지 않았습니다.
정식 배포/업로드 및 Firebase 콘솔 변경은 수행하지 않았습니다.
