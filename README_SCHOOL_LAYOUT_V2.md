# 케이네 서당 가구 배치 2차 미세조정

직전 gensokyo_rpg_school_layout_dev를 복사해 수정한 독립 개발본입니다.
정식 GitHub Pages 또는 Firebase 설정을 변경하지 않았습니다.
최신 결과는 이 문서와 school/LAYOUT_V2_* 파일을 확인하세요.

## 변경
칠판: u/v 500/14 → 536/59.
투영 후 X는 사실상 유지(약 -0.1), Y는 약 +22.4 게임 좌표만큼 내려갔습니다.
교탁과의 높이 간격을 줄이고 기존 목재 하단 프레임을 그대로 활용했습니다.
별도 받침대나 벽 그림을 추가하지 않았습니다.

뒤쪽 큰 책장: u/v 80/125 → 30/70.
벽 쪽으로 후퇴시켰으며 충돌 중심도 80/145 → 30/90으로 함께 이동했습니다.
실제 화면에서 뒤쪽 창문의 주요 채광 영역과 벽 기둥이 유지되는지 확인했습니다.
책장의 크기/그림은 그대로입니다.

칠판/책장은 별도 오브젝트이므로 배경을 덧칠하거나 새로 생성하지 않았습니다.
이동한 뒤 이전 자리에 그림이 남지 않습니다.
교탁, 케이네, 학생 4명/책상/착석 비율, 초상화/대화창과 출입구는 변경하지 않았습니다.
새 학습 시스템은 추가하지 않았습니다.

## 실행 및 복원
전체 ZIP 압축을 모두 푼 뒤 START_SCHOOL_DEV.bat를 실행하세요.
이전 개발 서버 창이 열려 있다면 먼저 닫습니다. 주소는 기존 localhost:8896입니다.
이전 화면이 남으면 Ctrl+F5로 새로고침하며 저장 데이터는 삭제하지 마세요.
패치 ZIP은 직전 서당 배치 개발본 루트 폴더에 덮어쓰면 됩니다.

school/terakoya.before-layout-v2.js는 이번 조정 직전의 원본입니다.
이를 school/terakoya.js 위에 복사하면 직전 칠판/책장 배치와 충돌 위치로 돌아갑니다.

## 실제 검증
로컬 Chromium, 1440×1000에서 실제 화면을 확인했습니다.
- F키 인간마을 → 서당 입장
- 입구에서 케이네까지 실제 경로 이동 및 F키 대화
- 기본/웃는 초상화 동일 표시 영역, 기존 수업 메뉴 5개 유지
- 인벤토리 열기/닫기
- 케이네 근처에서 출구까지 실제 경로 이동 후 F키 퇴장
- 중앙 통로와 케이네 접근 지점 유효, 교탁/학생 책상 충돌 유지
- 작은 책장을 제거한 기존 변경도 그대로 유지
- 대화와 이동 전후 저장 스냅샷 일치
- 테스트 저장의 봉마편/전/주먹밥/씨앗/농산물 새로고침 복원 일치
- 페이지 오류 0건

기존 HTML/CSS와 모든 이미지/에셋, 전투·농사·저장·클라우드 코드는 변경하지 않았습니다.
실제 Google 로그인/Firestore 동기화와 전 스테이지 완주는 다시 시험하지 않았습니다.
사용자의 실제 로컬/클라우드 저장 데이터에는 접근하지 않았습니다.
