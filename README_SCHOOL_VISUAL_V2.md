# 서당 내부 비주얼 미세조정 v2

정식 GitHub 배포본에는 업로드하지 않았습니다. 이전 1차 개발본과 백업은 그대로 보존했습니다.

## 변경 파일

실제 실행 코드 변경은 `school/terakoya.js` 한 파일뿐입니다. 본 설명서와 `school/VISUAL_V2_RESULTS.json`은 새 검증 문서입니다. `gensokyo_rpg.html`, `index.html`, 모든 PNG·음악 원본, cloud 파일, 외부 건물, 케이네·주인공, 기존 저장 키·스키마는 그대로입니다.

## 공통 조정

- 학생용 책상 폭 181 → 154(약 15% 축소). 원본 가로세로 비율을 유지합니다.
- 책상 표시를 아래로 12 월드 픽셀 이동해 상판 높이를 낮추었습니다. 렌더 순서 기준도 같은 만큼 보정했습니다.
- 학생+의자가 포함된 스프라이트의 세로 눌림을 제거했습니다. 높이는 140, 폭은 각 원본 비율에서 계산합니다. 기존 임의 크기 94×104는 사용하지 않습니다.
- 학생과 의자를 한 이미지 그대로 책상 쪽으로 이동합니다. 표시 이동량은 화면의 원본 맵 좌표로 약 오른쪽 21.3, 위 10.8 픽셀입니다.
- 네 자리 모두 같은 기준을 사용합니다. 개별 외형·앉은 자세·색상·책/필기도구를 재생성하거나 편집하지 않았습니다.
- 책과 필기도구는 기존 책상 이미지에 포함되어 있으므로 상판과 함께 축소·이동합니다.
- 지도 좌표, 통로와 충돌 다각형, 이동 엔진은 변경하지 않았습니다. 렌더링에만 보정을 적용합니다.

## 적용 방법

간단한 방법: 기존 개발 게임을 실행 중이면 명령 창을 종료한 뒤, 전체 개발본을 새 폴더에 압축 해제하고 `START_SCHOOL_DEV.bat`을 실행합니다. 시작 장소는 인간마을 중앙을 선택합니다.

작은 패치 사용: 이전 서당 개발 폴더를 먼저 복사해 보관하고, 패치 ZIP의 `school/terakoya.js`를 개발 복사본의 같은 위치에 덮어씁니다. 설명서와 검증 JSON도 함께 복사해도 됩니다. 새 배경이나 에셋을 다운로드할 필요는 없습니다. 브라우저에서 Ctrl+F5로 다시 불러오세요. 브라우저 저장 공간은 삭제하지 않습니다. 정식 GitHub 저장소에 복사하거나 Push하지 마세요.
