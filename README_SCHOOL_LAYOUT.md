# 케이네 서당 — 가구 배치 미세조정 개발본

기준: 최종 케이네 PNG 3종을 적용한 gensokyo_rpg_school_phase2_final_dev.
정식 GitHub Pages와 Firebase 콘솔을 수정하지 않은 별도 개발 복사본입니다.
이번 작업에서는 일본어 학습 시스템을 구현하지 않았습니다.
이전 README와 PHASE2/FINAL 결과는 해당 시점의 개발 기록입니다.
이번 변경과 테스트 결과는 본 문서와 school/LAYOUT_* 파일을 확인하세요.

## 배경/가구 확인
room-shell.png는 가구 없는 교실 배경입니다.
칠판·교탁·책장·학생 책상은 classroom-atlas.png에서 읽는 별도 오브젝트입니다.
따라서 배경 그림을 덧칠하거나 재생성하지 않고 배치 좌표만 조정했습니다.
이전 자리에 배경 가구 잔상이 남는 구조가 아닙니다.
모든 이미지 및 CSS는 기준본과 바이트 동일합니다.

## 수정한 위치
좌표는 기존 교실의 투영 전 u/v 좌표입니다. u/v 자체는 화면 픽셀이 아닙니다.

| 대상 | 이전 u/v | 변경 u/v | 설명 |
|---|---|---|---|
| 칠판 | 610 / 14 | 500 / 14 | 오른쪽 벽 중심 쪽으로 이동. 크기 300과 글씨/디자인 유지 |
| 교탁 | 650 / 150 | 500 / 165 | 칠판과 동일한 u축에 정렬. 크기 210 유지 |
| 케이네 | 790 / 125 | 690 / 110 | 교탁 오른쪽, 앞줄 학생의 책과 겹치지 않도록 배치 |
| 대화 접근 지점 | 820 / 260 | 690 / 270 | 케이네 새 위치에 맞춤. F키 범위/조작 방식은 유지 |
| 뒤쪽 큰 책장 | 80 / 125 | 그대로 | 기존 위치/크기 유지 |
| 학생 옆 작은 책장 | 950 / 600 | 제거 | 렌더링 등록과 해당 충돌 영역을 함께 제거 |

교탁 충돌도 같은 새 위치로 옮겼습니다.
학생 4명과 책상 4개의 좌표, 학생 키, 의자/책/책상 비율은 그대로입니다.
카메라, 바닥, 벽, 창문, 빛, 출입구, 기존 가림 처리 방식은 바꾸지 않았습니다.

## 실행
1. 전체 ZIP을 새 폴더에 모두 압축 해제합니다.
2. 이전 개발 서버 창이 열려 있으면 닫고 START_SCHOOL_DEV.bat 실행.
3. 인간마을 중앙에서 시작 → 서당 입구 F → 교탁 오른쪽 케이네에게 접근해 F.
4. 이전 화면이 남으면 Ctrl+F5. 로컬 저장을 지우지 마세요.
개발 주소는 기존 localhost:8896을 유지합니다.
패치는 최종 서당 2차 개발본의 루트 폴더에 덮어쓰는 용도입니다.
서당이 없는 정식 배포본에는 패치만 적용하지 마세요.

## 복원
school/terakoya.before-layout.js는 수정 전 전체 스크립트의 정확한 백업입니다.
이를 school/terakoya.js 위에 복사하면 이전 배치와 충돌 위치로 함께 돌아갑니다.
이미지 파일이나 저장 데이터를 되돌릴 필요는 없습니다.

## 테스트 범위
실제 브라우저에서 마을 → 서당 F키 입장, 입구에서 케이네까지 경로 이동,
케이네 F키 대화, 기본/웃는 표정 전환, 수업 메뉴, 인벤토리 열기/닫기,
대화 후 출구까지 경로 이동 및 F키 퇴장을 확인합니다.
옮긴 교탁의 충돌, 중앙 통로, 작은 책장 삭제 지점의 이동 가능 여부,
학생 책상 4개의 기존 충돌, NPC 5명 유지도 확인합니다.
서당 상호작용 전후 저장 스냅샷과 테스트 저장의 새로고침 복원을 비교합니다.
결과 상세는 school/LAYOUT_TEST_RESULTS.json에 기록합니다.
기준본 전체 파일 비교는 school/LAYOUT_FILE_VERIFICATION.json에 기록합니다.

실제 Google 로그인/Firestore 동기화, 모든 스테이지/EXTRA 완주 및 Windows 실행기는
이번 변경에서 다시 시험하지 않습니다. 관련 기존 코드와 모든 기존 이미지/CSS,
로컬/클라우드 저장 키 및 검색 제외 설정은 변경하지 않았습니다.
사용자의 실제 저장 데이터에는 접근하거나 변경하지 않았습니다.
