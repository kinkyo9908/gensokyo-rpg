# 조온 NPC 배치 개발본

기준: 정식 main `44462678a236af52263f23bd6d5fa9bb2fa87f50` (서당 v15.4).
개발 브랜치: `dev/joon-npc`. main 및 Pages 설정은 변경하지 않는다.

## 적용 범위

- 게시판 오른쪽 아래 `vp(1220,315)`에 고정형 요리가미 조온 한 명 추가.
- 기존 주민과 같은 렌더 배율로 캐릭터 실질 높이 74 사용.
- 원본 맵 PNG의 모자 위 y=127, 신발 바닥 y=1149, 발 접점 x=727을 기준으로 전체 원본을 비율 유지하여 표시한다. PNG를 자르거나 수정하지 않는다.
- 기존 깊이 정렬에 발 위치를 등록한다. 기존 지형 충돌과 게시판 조사 설정을 변경하지 않는다.
- F키 대화는 기존 resident 대화 상태/버튼/키보드 진행을 재사용한다.
- 임시 안내 세 문장에 기본 미소, 얄미운 웃음, 못마땅함을 연결한다. 세금 상태를 의미하지 않는다.
- 초상화 전용 CSS는 `.joon-dialogue`에만 적용한다. 기존 다른 NPC의 크기나 배치를 변경하지 않는다.
- 세금 계산, 재화 차감, 체납, 보상, 첫 등장 이벤트 및 컷신은 없다.

## 변경 파일

`gensokyo_rpg.html` 마지막에 조온 CSS/JS 로딩을 한 줄 추가.
`npc/joon.js`, `npc/joon.css`, `npc/assets/joon-{map,normal,smirk,displeased}.png` 추가.
그 외 게임 코드·전투 데이터·단어장·저장/클라우드 모듈은 원본 그대로 유지한다.
첨부 네 PNG는 원본과 SHA-256이 일치한다.

## 저장과 테스트

이 개발 브랜치는 향후 정식 통합을 위한 코드이므로 기존 운영 저장 키/클라우드 코드를 그대로 보존한다.
**동작 확인에는 별도로 만든 격리 테스트 복사본을 사용한다.** 격리본은 기존 `school-test` 구성과 동일하게
`gensokyo-rpg-school-test:permanent`, `gensokyo-rpg-school-test:lastVisit`만 사용하고 Firebase 설정/클라우드 모듈을 HTML에서 로딩하지 않는다.
CSP의 `connect-src 'self'`와 외부 스크립트 제한도 유지한다.
사용자의 실사용 세이브, Google 계정, Firestore 문서에는 테스트 쓰기를 하지 않았다.

별도 `gensokyo-rpg-school-test` 저장소 쓰기는 GitHub Connector의 403(Resource not accessible by integration)으로 막혀 원격 테스트 배포를 진행하지 않았다.
저장소 권한을 우회하거나 정식 main을 배포 소스로 이용하지 않는다.

## 검증 한계

로컬 Chromium 자동화와 실제 캡처로 배치 및 대화를 검사했다.
실제 Google 로그인, Firestore 업로드/다운로드, 일본어 음성의 청취 품질, 모든 스테이지의 전투 완주까지는 이번에 검증하지 않았다.
전투 회귀 검사는 1-1~1-5 및 EXTRA 입장과 기존 학습/농사/인벤토리/합성 세이브 복원을 확인한다.
원본 HTML 내부 템플릿 문자열을 주소로 해석하는 간헐적 요청이 관찰되어 별도 결과 JSON에 기록했다. 해당 원본 아이콘 코드에는 이번에 손대지 않았다.

검증 결과: NPC/격리 테스트 34개, 기존 게임 회귀 검사 60개 통과. 상세 목록은 `verification/` JSON 참조.
