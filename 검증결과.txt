v80 실제 수행한 검증

1. 기존 v79의 네 개 루트 스크립트를 대조했습니다. 이미지/음악 URL과 전투 iframe 기준 경로 설정 이외의 코드는 동일합니다.
2. 126개 에셋의 SHA-256을 확인했습니다. 이미지 115개는 이미지 디코더에서 무결성 검사에 통과했습니다. 음악 9개와 글꼴 2개는 원본 바이트가 보존되었습니다. 음악 9개 모두 음원 분석 도구에서 정상 인식되었습니다.
3. 루트 및 생성된 전투 스크립트의 JavaScript 구문 검사에 통과했습니다.
4. Node VM에서 1-1~1-5와 EXTRA의 실제 진입 로직을 실행했습니다. 모든 에셋 참조가 존재하며, 전투 HTML에 대용량 base64가 남지 않습니다.
5. 일반 체크포인트, 보상 처리, 1-5→EXTRA 진입, 중복 진입 차단, 취소 및 복귀 처리를 확인했습니다.
6. 미스티아 80개/27·27·26, 페이즈 종료 시 HP 감소, 정규 클리어 후 EXTRA 분기를 확인했습니다.
7. 프리즘리버 전체 450개 복습·480개 출제, 숨겨진 4페이즈, 자동 대사, BGM 볼륨 변화, 재도전을 확인했습니다.
8. 기존 SaveManager의 저장/복원 테스트에서 주먹밥, 봉마편, 전, 씨앗, 농산물, 밭 6개, 학습 기록 및 NPC 기록이 보존되었습니다.
9. 저장 복구/가져오기에서 저장 문자열이 그대로 유지되고, 잘못된 JSON은 기존 저장을 덮어쓰지 않음을 확인했습니다.

미확인 항목
이 환경에는 실행 가능한 Chrome 및 Windows PowerShell이 없습니다. 실제 Windows 런처 실행, Chrome의 최종 메모리 사용량, 화면 출력 및 음악 청취는 직접 확인하지 못했습니다.
기존 file:// 저장 영역 복구는 브라우저의 파일 경로 처리 방식에 따라 달라집니다. 읽어주세요.txt의 동일 파일명·경로·프로필 절차를 따라주세요.
