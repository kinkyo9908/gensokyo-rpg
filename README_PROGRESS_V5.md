# 케이네 서당 v5 — 제1권101개·이어 학습

이번 개발본의 최신 안내입니다. 이전 README/보고서는 과거 단계 기록으로 보존했습니다. 정식 GitHub Pages는 수정하지 않았습니다.

## 실행과 사용

1. 전체 ZIP을 새 폴더에 풉니다. 정식 게임 폴더에 덮어쓰지 않습니다.
2. 기존 개발 서버가 켜져 있으면 해당 콘솔을 종료한 다음 `START_SCHOOL_DEV.bat`을 실행합니다.
3. 기존 `http://localhost:8896/` 주소를 유지합니다. HTML 파일 직접 실행 대신 로컬 서버를 사용합니다.
4. 인간마을 → 서당 입구 F → 케이네 F → 새로운 학습 → 책장 제1권 → 학습 시작.
5. 진도가 있으면 책장에 현재 진도와 **이어 학습 · N번째부터**가 표시됩니다. 케이네 메뉴의 **이어 학습**으로도 바로 이어갈 수 있습니다.
6. 10개 단위 채점 안내에서 계속 학습 또는 오늘은 여기까지를 고릅니다. 101번째는 별도 완독 화면입니다.
7. 학습한 단어 다시 보기에서는 이미 채점한 위치를 입력해 열람할 수 있습니다. 다시 풀어도 최초 진도와 결과를 덮어쓰지 않습니다.
8. Esc/책장으로는 책장으로, 책장에서 Esc는 수업 메뉴로, 다시 Esc는 대화 종료입니다.

점수·경험치·재화·아이템 등 보상은 없습니다. 완독은101개 모두 채점했다는 뜻이며, 모든 문제 정답을 뜻하지 않습니다. 설명·예문은 임의 추가하지 않았습니다. 기존3단어 테스트는 별도로 유지하고 진도 저장을 하지 않습니다.

## 저장

기존 키와 saveVersion은 유지하고 `schoolLearning` 선택 필드만 추가했습니다. 채점 완료 시 동기 로컬 저장을 먼저 완료한 뒤 진도를 확정합니다. 저장 실패 시 다음 단어로 넘기지 않고 재시도합니다. 전투 학습 기록106개와 스테이지 기록은 별도이며 변경하지 않습니다.

기존 CloudSync의 저장 묶기·최소 간격·충돌 선택과 오프라인 처리를 그대로 사용합니다. 실제 Google/Firebase 통신은 검증하지 않았으며, 모의 업로드·다운로드만 확인했습니다. Firebase 설정/보안 규칙/Spark 요금제는 변경하지 않았습니다.

자세한 저장 구조·원본 대조·테스트·미검증 항목은 `VOLUME1_PROGRESS_REPORT.md`를 확인해 주세요.

## 패치 적용 및 복구

패치 ZIP은 **서당 v4 개발본**의 게임 루트에 풀어 적용합니다. 다음4개 기존 파일과 새 진도 모듈이 함께 필요합니다.

- school/terakoya.js
- school/terakoya.css
- school/volume1-words.json
- cloud/sync-core.mjs
- school/learning-state.mjs (새 파일)

변경 전 파일은 `school/backup-before-progress/` 안에 원래 school/cloud 경로를 유지해 넣었습니다. 원래 위치로 복사하면 코드와 수업 자료를 v4로 되돌릴 수 있습니다.

**구버전은 새 서당 진도 필드를 보존하는 기능이 없습니다.** 롤백 또는 구버전과 클라우드 기록을 교차 사용하기 전에 기존 ☁저장 → 현재 로컬 기록 백업으로 전체 저장 JSON을 보관해 주세요. v5는 기존 저장을 정상적으로 읽지만, 구버전에서 새 필드를 다시 저장하는 역방향 호환성은 별개입니다.

원본 v4 전체 ZIP은 그대로 보존했습니다. 정식 배포본에는 이번 파일을 적용하지 않았습니다.
