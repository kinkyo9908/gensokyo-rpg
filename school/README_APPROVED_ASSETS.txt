환상향 RPG - 케이네 서당 리소스 적용 지시서

현재 서당 2차 개발본에 첨부한 PNG 3개를 사용해 주세요.
- keine_map.png: 케이네 고정형 서당 NPC. 비이동, 걷기 모션 없음.
- keine_dialogue_normal.png: 기본 표정 대화 초상화.
- keine_dialogue_smile.png: 눈 감고 웃는 대화 초상화.

아트 리소스를 새로 생성하거나 복장/표정/헤어/모자/책/픽셀을 임의 수정하지 마세요. 원본 PNG 그대로 사용하세요. 두 대화 초상화는 동일한 1024x1536 캔버스입니다. 표정 전환 때 동일한 위치/배율을 사용하고 초상화 머리, 양팔, 머리카락이 잘리지 않게 하세요.

현재 서당 내부 2.5D 배경, 학생 4명 및 책상 배치, 케이네 F키 상호작용, 기존 대화/학습메뉴, 입·퇴장, 이동/충돌 처리를 보존하세요. 교탁/케이네 정렬과 동선만 필요한 만큼 미세조정하세요. 중앙형 대화창은 서당 개발본에서만 테스트하고 기존 환상향풍 목재/화지 UI를 유지하세요.

PNG에는 알파 채널이 있습니다. 다만 머리카락 주변 잔여 픽셀 가능성이 있으므로 어두운/밝은 교실 배경 위에 표시해 직접 검사해 주세요. 별도 재렌더링/배경 생성 없이 문제 지점만 보고하세요.

정식 GitHub Pages 배포본과 원래 저장 데이터는 수정하지 마세요. 스테이지, EXTRA, 농사, 인벤토리, 로컬/클라우드 저장, 검색 제외 설정 등 기존 기능 유지. 도감용 전신 자산은 이번 범위에서 제외.

결과물은 별도 개발본과 케이네 기본/웃는 대화 화면 및 맵 NPC 배치 스크린샷, 테스트 결과를 제공해 주세요.
