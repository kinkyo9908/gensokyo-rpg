# 📜 환상향 RPG — 케이네 서당 어휘 두루마리 제6~10권 인수인계

유카리~! 이번에는 케이네 선생님이 준비한 **어휘 두루마리 제6~10권, 총 400개 단어**를 전달할게.

## 적용 원칙

- 기존 제1~5권의 학습 시스템과 디자인은 유지해 줘.
- 제6~10권은 각각 80개 단어, 10개씩 8묶음으로 구성해 줘.
- 단어의 번호, 일본어 표기, 읽는 법, 한국어 뜻을 정확하게 보존해 줘.
- 기존 단어 데이터와 중복되는 어휘는 먼저 보고해 줘. 임의로 삭제하거나 다른 단어로 교체하지 말아 줘.
- TTS, 문제 풀이, 채점, 오답 복습, 권별 진도는 기존 시스템을 재사용해 줘.
- 케이네 서당은 순수 일본어 학습 콘텐츠이므로 RPG 경험치나 아이템 보상은 추가하지 말아 줘.
- 기존 학습 기록과 저장 데이터는 유지해 줘.
- 먼저 데이터 검증 및 적용 계획을 확인하고, 테스트판에서 구현해 줘. 정식 배포는 별도 승인 후 진행해 줘.

유카리, 데이터 적용 전 다음 사항을 확인해 줘.

1. 제6~10권에 각각 정확히 80개씩, 총 400개가 등록되었는지 확인.
2. 번호와 학습 묶음 순서가 올바른지 확인.
3. 한자·가나·한국어 뜻이 누락되거나 깨지지 않았는지 확인.
4. 읽는 법이 별도로 적히지 않은 가타카나·히라가나 단어는 표기 자체를 읽는 법으로 처리.
5. 기존 제1~5권과 중복 단어를 검색하고, 발견 시 권·번호를 보고.
6. 일본어 TTS와 문제 출제 시 한자 표기와 읽는 법이 정확하게 연결되는지 확인.
7. 기존 학습 진도, 오답 기록, 저장 데이터의 호환성 유지.
8. 단어 원고는 JLPT N5 전용으로 엄격하게 검증된 목록이 아니므로 난이도 분류가 필요한 경우 별도로 보고.
9. 기존 두루마리 보관함 디자인과 학습 프레임을 최대한 유지.
10. 검증이 끝난 테스트판에서 제6~10권 각각 학습·문제 풀이·채점·복습이 정상 작동하는지 확인.
