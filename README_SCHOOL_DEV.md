# 케이네의 서당 · 1차 개발 복사본

정식 GitHub Pages에는 업로드하지 않았습니다. 기준 커밋: `6fbdd02c2a6fb9b685a1b916187175a826332557` (Add cloud saves and noindex metadata).

## 실행

1. 전체 개발본 ZIP을 **새 폴더**에 압축 해제합니다. 기존 정식 게임 폴더에 덮어쓰지 않습니다.
2. `START_SCHOOL_DEV.bat`을 실행하고 열린 명령 창을 유지합니다.
3. `http://localhost:8896/`에서 게임을 시작합니다.
4. 유카리의 시작 장소 선택에서 **인간마을 중앙**을 선택합니다.
5. 중앙 상점가에서 왼쪽 위의 기와지붕 서당으로 이동합니다. `修学` 현판, 푸른 출입구 천과 돌계단이 있는 건물입니다.
6. 계단 앞에서 **F · 들어가기 · 케이네의 서당**을 선택합니다.
7. 책상 사이 빈 바닥 클릭 또는 WASD/방향키로 이동합니다. 뒤쪽 오른편 케이네에게 접근해 F를 누릅니다.
8. 대화 후 수업 메뉴를 열 수 있습니다. 학습 기능은 아직 연결하지 않았으며 준비 안내만 표시합니다.
9. 앞쪽 계단으로 이동하거나 근처에서 F로 인간마을에 돌아갑니다.

독립된 개발용 주소/포트이므로 기존 GitHub Pages 및 8765 포트의 로컬 저장 공간을 사용하지 않습니다. 같은 저장 키는 그대로 유지합니다. 기존 기록으로 시험하려면 원래 게임에서 저장 JSON을 내보내고 **개발 주소의 시작 화면**에서 가져옵니다. 브라우저의 저장 공간을 삭제하지 마세요.

클라우드는 정식본과 같은 Firebase 설정을 유지합니다. 이번 서당 시험은 **비로그인 로컬 플레이**로 가능합니다. 로그인해 같은 계정의 기록을 선택하면 실제 클라우드 저장과 연결되므로 시험 기록을 실제 진행 위에 업로드하지 않도록 기록 선택 내용을 확인하세요. Firebase 요금제와 보안 규칙 변경은 필요하지 않습니다.

## 구현

- 기존 마을의 테라코야 부지를 서당으로 활용. 다른 건물, 주민 위치와 배경 원본은 유지.
- 새 서당 외관을 기존 부지 위에 표시. 출입 판정을 돌계단 앞에 배치.
- 독립 맵 `terakoya`: 높은 사선 쿼터뷰, 앞 벽이 열린 목조 디오라마, 밝은 창가.
- 빈 바닥·벽 구조와 별개로 교탁, 판서판, 책장 2개, 책상 4개를 렌더링.
- 기존 케이네 스프라이트와 기존 준하 스프라이트/걷기 모션 사용.
- 일반 마을 학생 4명은 각기 독립된 고유 ID로 등록. 정지 상태로 공부하며 이동 AI/퀘스트/전투/보상이 없음.
- 책상과 의자에 각각 충돌 영역. 중앙 통로, 출입구, 케이네 접근 지점을 연결.
- 가구와 사람의 발밑 Y 좌표를 공유하는 정렬 큐로 앞뒤 가림 처리.
- 기존 주민 대화 프레임과 입력 차단을 재사용. 케이네는 기존 캐릭터 시트를 잘라 초상화로 사용하며 새 디자인을 만들지 않음.
- 수업 메뉴 4개 및 대화 종료. 각 수업 선택은 `gensokyo-school-lesson-request` 이벤트만 발생 (`implemented:false`). 실제 학습, 보상, 단어장 변경 없음.

## 비주얼 조정 범위

첨부 시트는 디자인 기준으로 사용했습니다. 시트를 통째로 배경으로 붙이지 않았습니다. 실제 가구 충돌과 이동 통로를 확보하기 위해 책상 간격, 케이네의 서 있는 위치, 책장 위치는 플레이 가능한 폭에 맞추었습니다. 교실 가구와 학생은 별도 게임 자산으로 제작했으며, 참고 시트의 임시 케이네 캐릭터는 복제하지 않았습니다. 원래 실내로 사용하던 평면 2D 집 배경도 재사용하지 않았습니다.

## 실제 확인

- Chromium에서 게임 초기 로딩, 기존 시작 장소 선택 및 마을 시작.
- 돌계단 앞 기존 F키 상호작용으로 서당 진입, 정상 출현, 기존 이동/경로 탐색.
- 출입구·대화 지점의 이동 가능 판정, 중앙 통로 연결, 책상·의자 충돌, 큰 이동값에 대한 벽 통과 방지.
- 케이네 대화, Enter/F 진행, 수업 메뉴 5개, 준비 안내, Esc 종료, 마을 복귀.
- 서당 입퇴장 및 대화 전후 저장 스냅샷 동일.
- 기존 형식의 테스트 저장(봉마편 6, 주먹밥 2, 소지금 1234, 씨앗/수확물, 심어진 밭, EXTRA 클리어)을 불러오고 재저장·재접속해 보존 확인. 사용자 실제 계정 저장은 사용하지 않음.
- 인벤토리 I키, 미요이 메뉴, 미노리코 대화, 개별 밭 씨앗 선택창.
- 기존 1-1~1-5 및 EXTRA 전투 화면 진입과 복귀. **전체 전투 완주 테스트는 아님.**
- 1440×1000 및 390×844에서 화면과 수업 메뉴 점검.
- 기존 에셋 126개 및 cloud 파일의 바이트 동일성 확인, 페이지 실행 오류 0개.

- 모든 스테이지와 보스의 전체 완주, 모든 화면 비율에서의 육안 점검.

## 백업·복구 및 배포

백업 ZIP은 기준 커밋의 코드와 에셋이며, 개인 브라우저 저장 및 Firestore 사용자 문서 백업은 포함하지 않습니다. 개인 기록은 게임의 내보내기로 별도 보관하세요.

개발 결과를 실제 플레이로 확인하기 전에는 정식 저장소에 복사하거나 Push하지 마세요. 정식본 복구가 필요하면 별도 백업 폴더에 압축 해제한 뒤 기존 배포 이력과 대조합니다. 브라우저 저장 삭제나 Firebase 초기화는 하지 않습니다.
